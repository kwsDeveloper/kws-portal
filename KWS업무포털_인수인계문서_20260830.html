01

프로젝트 개요

서비스명KWS 업무 포털 (kws-work-portal)

목적사내 자주 사용하는 업무 링크를 카테고리별로 정리·공유하는 포털 페이지

대상 사용자대한사회복지회 전 직원

운영 형태GitHub Pages (무료 정적 호스팅) + Supabase (데이터 저장)

특징단일 HTML 파일(SPA) 구조 / 관리자 로그인 후 실시간 편집 / 다기기 동기화

02

서비스 구성 및 기술 스택

구성 요소기술/서비스역할
프론트엔드 HTML · CSS · Vanilla JS (단일 파일) 포털 UI 전체, 관리자 패널 포함
호스팅 GitHub Pages 정적 파일 서빙, 무료·무제한 트래픽
데이터베이스 Supabase PostgreSQL 링크 목록·설정값 영구 저장·동기화
API 프록시 Supabase Edge Function (portal-api) 서버측 DB 접근 (Service Role 키 보호)
폰트 Google Fonts (Montserrat, Nanum Gothic 등) 동적 로드, 관리자 패널에서 변경 가능
⚠ 보안 주의   Supabase Service Role 키는 반드시 Edge Function 환경 변수(SUPABASE_SERVICE_ROLE_KEY)에만 저장합니다. 클라이언트 HTML에 절대 노출하지 마세요.

04

데이터베이스 구조 (Supabase PostgreSQL)

▸ public.links — 링크 목록

컬럼타입설명
idtext PK링크 고유 ID (타임스탬프 기반)
cattext카테고리명 (왼쪽 라벨)
nametext링크 표시명
urltext대상 URL (#이면 미설정)
statustextactive / disabled / coming-soon
sort_orderinteger표시 순서
link_fonttext (null 가능)링크별 폰트 (현재 미사용, 전역 설정으로 대체)
link_sizetext (null 가능)링크별 크기 (현재 미사용, 전역 설정으로 대체)

▸ public.config — 설정값

key설명예시값
orgName조직명 (헤더 표시)대한사회복지회
adminPw관리자 패널 비밀번호(설정된 값)
fontKey전체 기본 폰트Montserrat
headerLogo헤더 로고 (base64 이미지)data:image/png;base64,...
bgLogo배경 워터마크 로고 (base64)data:image/png;base64,...
catFont카테고리 라벨 전역 폰트Nanum Gothic
catSize카테고리 라벨 전역 크기13px
linkFont링크명 전역 폰트Montserrat
linkSize링크명 전역 크기13px
05

Supabase Edge Function (portal-api)

함수명portal-api

위치Supabase 대시보드 → Edge Functions → portal-api

역할Service Role 키를 서버 환경 변수로 보관하고, 클라이언트 대신 DB에 읽기·쓰기 수행

action 파라미터HTTP 메서드동작
loadGETconfig + links 전체 로드 (포털 초기화)
setConfigPOSTconfig 테이블 단일 키 upsert
saveLinkPOSTlinks 테이블 단일 행 upsert (추가·수정)
deleteLinkPOSTlinks 테이블 단일 행 삭제
⚠ 함수 수정 시   Supabase 대시보드 → Edge Functions에서 직접 편집하거나, Supabase CLI로 배포합니다. SUPABASE_SERVICE_ROLE_KEY 환경 변수는 Secrets에 등록되어 있으며 별도 확인이 필요합니다.
06

주요 기능 및 관리자 패널 안내

일반 사용자

  • 카테고리별 업무 링크 목록 확인
  • 링크 클릭 → 외부 사이트 새 탭 열기
  • 다크/라이트 모드 토글
  • 다기기에서 동일 데이터 자동 동기화

관리자 (우상단 자물쇠 아이콘)

  • 링크 추가 · 수정 · 삭제 · 순서 변경
  • 카테고리 관리
  • 조직명 변경
  • 헤더 로고 · 배경 워터마크 이미지 업로드
  • 전체 폰트 · 칼럼별 폰트/크기 설정
  • 관리자 비밀번호 변경

초기 비밀번호별도 전달 (보안상 이 문서에 기재 안 함)

비밀번호 변경관리자 패널 → 설정 탭 → 관리자 비밀번호 변경

비밀번호 분실Supabase 대시보드 → config 테이블 → adminPw 행 직접 수정

07

파일 구조 및 배포 방법

kws-work-portal/
  ├── index.html          ← 포털 전체 소스 (단일 파일)
  ├── logo.png            ← 기본 포함 로고 (필요 시 교체)
  └── README.md

배포 절차 (GitHub Pages 자동 배포)

  1. index.html 수정 — 로컬에서 편집 (VS Code 또는 Claude Code 사용)
  2. git add index.html → git commit -m "수정 내용"
  3. git push origin master — 약 1~2분 후 자동 반영
  4. 확인 — https://kwsdeveloper.github.io/kws-work-portal 에서 브라우저 새로고침
⚠ 배포 전 확인   API 키나 비밀번호 등 민감 정보가 index.html에 하드코딩되지 않았는지 반드시 확인하세요. 데이터는 Supabase Edge Function을 통해서만 접근합니다.
08

유지보수 가이드

상황조치 방법
링크가 안 열림 관리자 패널 → 링크 수정 → URL 확인 / 상태 활성으로 변경
데이터가 저장 안 됨 (오프라인 모드 표시) Supabase 대시보드에서 Edge Function 로그 확인 (Functions → portal-api → Logs)
비밀번호 분실 Supabase Table Editor → config → adminPw 행 value 직접 수정
Supabase 무료 플랜 일시 중단 (7일 비활성) Supabase 대시보드에서 프로젝트 재활성화 버튼 클릭
로고/배경 이미지 깨짐 관리자 패널 → 설정 → 이미지 재업로드 (1MB/2MB 이하 PNG 권장)
폰트가 적용 안 됨 Google Fonts 서버 상태 확인 / 브라우저 캐시 삭제(Ctrl+Shift+R)
Edge Function 오류 (500) Supabase → Functions → portal-api → Logs에서 에러 메시지 확인
